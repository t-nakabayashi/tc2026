## 1. 参加条件と提出物

参加には開発・成果公開、運営協力と情報交換、安全配慮、日本語での連絡・対話が求められる。
登録は1チーム1台。動力走行には安全管理責任者とオペレータの別々の2名が必要。
募集ページでは受付が7月10日まで延長され、現在は終了。入金期限は7月31日。
参加費は団体70,000円（クーポンあり60,000円）、個人15,000円（同10,000円）。
[出典: 参加チーム募集](https://tsukubachallenge.jp/2026/about/registration)

初回実機参加の前日までに、代表者自署の誓約書をPDFで事務局へ提出する。
安全チェックシートは各実験日に事前記入して提出。名札は全員分を用意する。
チェックシートは**9月20日更新版**を使用。本体高さの説明が追加された。
[出典: 配付書類](https://tsukubachallenge.jp/2026/teams/forms)、[更新告知](https://tsukubachallenge.jp/2026/info/15896)

自己紹介・進捗報告、参加レポート投稿とシンポジウム発表は原則必須。LT大会は任意。
公開データセットやシミュレータは個々のライセンスと引用条件に従う。
[出典: 活動内容](https://tsukubachallenge.jp/2026/about/activities)

## 3. 必須課題と走行条件

必須課題は約2.2 kmの自律走行。最初の約400 mが確認走行区間。
ホテル周辺を時計回りに周回し、車体全体がゴールを越えてから自律停止する。
停止線は手前1 m〜奥0.5 mに車体の一部が入り、全ての部位が奥0.5 mを越えないこと。
道路端は手前1.5 m以内に一部が入り、どの部位も道路端を越えないこと。
停止後は安全確認・周囲への再開宣言を伴うオペレータ操作で再開する。

横断待機列では追い越さず、前が空けば進む。停止線と道路端でそれぞれ停止する。
選択Bを行わない場合は、人が青信号と残留車両なしを確認して横断を開始する。
青点灯・点滅の間に渡り切れる所要時間を事前検証する。
ホテル西側の朱色路側帯で通過不能なら、自律停止後に非常停止し、台車等で退避する特例がある。
現地の通行範囲・コーン・コース図と特例の詳細は原文で確認する。
[出典: 課題](https://tsukubachallenge.jp/2026/regulations/tasks)

## 4. 評価と制限時間

| 評価 | 条件の概要 |
| --- | --- |
| マイルストーン1 | 確認走行区間の成功 |
| マイルストーン2 | ホテル周回完了地点まで成功 |
| マイルストーン3 | ゴールまで完走 |
| 課題達成 | 完走＋選択課題2項目以上 |
| 完全課題達成 | 完走＋A・B・D1・D2・Eの全て |

速度による順位付けはない。D2成功時はD1も成功として数える。
本走行・記録走行は100分以内、スタートコールから1分以内に開始線、2分以内に20 mを越える。
確認走行区間で3分、横断待機列で前が空いているのに90秒の停滞も失敗条件（前進1 mが目安）。
禁止区域進入、停止領域逸脱、許されていない人の介入、環境改変なども失敗要因。
非常停止は原則失敗だが外的危険等の例外があり、本部の判断を要する。危険回避を優先する。
[出典: 評価方法](https://tsukubachallenge.jp/2026/regulations/evaluation)

## 5. 選択課題

- A: 事前走行・センサ等での計測をしない駐車場エリアを通過。目視・既存地図利用は認められる。
- B: 信号と交差点の安全を認識して往復の横断を自律開始する。
- C: **2026年度は実施しない**。
- D1 / D2: 配達先認識と訪問 / 荷物の自動回収・投入。
- E: 指定区間で最初にすれ違ったロボット番号を報告する。

選択課題は任意で、本走行の出走前に実施／不実施を申告する。細かな成功条件や失敗後の再開条件は原文を参照。
[出典: 課題](https://tsukubachallenge.jp/2026/regulations/tasks)、[評価方法](https://tsukubachallenge.jp/2026/regulations/evaluation)

## 6. ロボット仕様・停止系

| 項目 | 上限・条件 |
| --- | --- |
| 全長 / 全幅 | 1.2 m以下 / 0.7 m以下 |
| 全高 | 0.6〜1.8 m。本体はセンサ類・ヘッドサポートを除き1.2 m以下 |
| 重量 | 125 kg以下 |
| 速度 | 6 km/h以下（換算約1.667 m/s）。誤動作時も超過しないこと |
| 番号板 | 縦11×横13 cm。前方を含む3か所以上、下端地上0.2 m以上 |
| 状態表示 | 前後から見える色＋文字。自律は緑、操縦は黄 |

本体の非常停止は主電源と別の赤ボタン・黄土台で、誤動作時も確実に停止でき、退避可能な構造が必要。
**有線・無線コントローラによる停止は非常停止として認められない。**
本走行・記録走行・確認走行では操縦コントローラを操作不能にする。
追加の無線非常停止はISO 13849-1 PL dを満たす製品に限定される。
突起、巻き込み、熱・感電、転倒の対策も必要。これらは手動のデータ取得時にも適用される。
[出典: ロボット仕様条件](https://tsukubachallenge.jp/2026/regulations/specs)

## 7. 実験運用・安全

安全チェックは毎実験日に受け、合格前の動力走行は禁止。安全合格は当日限り。
確認走行認定は当年度本走行日まで有効だが、別のロボットや構成の大幅変更では再認定が必要。
認定前は確認走行区間の先で自律走行できない。安全管理責任者は周囲監視に専念し、撮影を兼任しない。
走行は指定日・時間・コース内に限り、責任者とオペレータが随行する。
[出典: 安全事項](https://tsukubachallenge.jp/2026/regulations/safety)、[用語](https://tsukubachallenge.jp/2026/regulations/terms)

環境は一般の歩行者や工事を含む現状のまま利用し、独自ランドマーク設置や植栽変更は禁止。
人が介在しない通信サービスは使用可能。自前RTK基地局も可能だがコース上への設置は避ける。
乗車走行は禁止。事故・問題は事務局に報告し、その指示に従う。
[出典: 実験条件](https://tsukubachallenge.jp/2026/regulations/experiments)

記録走行は本部へ申請し、随行委員なしで自己記録・申告する。成功・失敗とも記録する。
時刻、時間、終了位置、距離、達成段階、動画・ログURLを残す。記録の公開はチームで実施判断する。
[出典: 確認・記録走行](https://tsukubachallenge.jp/2026/teams/records)

## 10. 更新手順

出走準備・ルールに関わる実装変更の前に、公式トップのお知らせと関連ページを再確認する。
変更があれば本書の確認日・出典台帳・実装確認事項・PDFを同時に更新する。
数値の変更と文面の解釈変更を区別し、食い違う記載は勝手に統合しない。
`python3 build_pdf.py`（reportlabが必要）で閲覧用PDFを再生成できる。
原文の一括転載ではなく、要約と公式リンクを維持する。
