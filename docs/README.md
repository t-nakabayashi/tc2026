# docs 索引

ワークスペース全体に関わる文書の一覧である。文書の種別定義、章立て、記載粒度、配置規約は
[ドキュメント整備方針.md](ドキュメント整備方針.md) を正とする。

特定パッケージに閉じる文書は `src/<pkg>/README.md`（運用手順）と `src/<pkg>/docs/`（詳細設計書）に
あり、ここには列挙しない。パッケージの一覧は [ワークスペース README](../README.md) を参照する。

---

## 読む順序

初めて読む場合は次の順に参照する。

1. [システム構成](システム構成.md)：データと指令の流れ。
2. [共通起動](../src/icart_bringup/README.md)：実機・模擬とセッションの準備。
3. [実機ハードウェア統合](../src/icart_bringup/docs/実機ハードウェア統合.md)：接続・取付・Joy 操作。
4. [走行システムの機能と制約](走行システムの機能と制約.md)：停止状態、回避幅、未観測、位置品質の限界。
5. [公式情報参照ガイド](references/tsukuba_challenge_2026/README.md)：大会条件の原文と確認事項。

同梱経路やシミュレーションは、現地確認済みの本番経路の代わりにはならない。

一方向のみとする。そのため、ここでは個別の資料を列挙しない。
