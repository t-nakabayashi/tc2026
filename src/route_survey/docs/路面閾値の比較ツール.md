# 路面閾値の比較ツール

## 役割

`tools/evaluate_ground_thresholds.py` は[空き空間サンプル](空き空間参照サンプル.md)の
保存入力を使い、閾値ごとの路面セルと進路候補を比較するオフラインツールである。
走行ノードの閾値を変更したり、速度を配信したりする機能はない。
候補数の増加と、歩道検出の精度向上は区別する。

## 判定条件

地表面と現在の障害物は別の層として扱う。人やコーンで遮られたことだけで
蓄積済みの地表を消さず、現在の物体がある場所は進路候補から除く。
未観測・下方段差・現在の障害物の制約は閾値比較でも維持する。

`GroundThresholds` の既定値は次のとおり。

| 条件 | 既定値 |
|---|---|
| 平面推定の種点に許容する強度 | 30以下 |
| 材質拒否の強度閾値 | max(30, 種点強度中央値×2.5) |
| 平面からの支持高さ | 5.5 cm |
| 地面支持に必要な点数 | 3 |
| 材質拒否に必要な点数 | 3 |
| 材質拒否に必要な点の割合 | 0（割合制約なし） |
| 凹凸の高さ・必要点数 | 6.5 cm・3点 |

平面の外れ値除去にはMADから求めた雑音推定を使う。
比較設定は `configurations()` に定義した14通りで、強度倍率、凹凸、支持高さ・点数、
材質点数・割合を変える。地面蓄積、0.15 mセル、車体半径0.40 m、
経路選択の方法を共通にし、同一の入力と基準設定の直前曲率で比較する。

## 評価値の意味

`summary.json` は走行場面の候補数、GNSS途絶模擬中の内訳、基準設定との一致、
障害物・下方段差セルの保持を集計する。
これらは記録済みの観測に対する判定であり、変更した進路を走った結果ではない。
重力姿勢もbag内で得た固定校正を全場面へ適用する事後解析である。

合成入力には次の反例を含める。

- 同一平面の舗装と芝生に近い強度を与える：幾何・強度だけの材質識別の限界。
- 既観測の地面に9 cmの段差点を重ねる：凹凸閾値を緩めた際の段差許可。
- 1セル内に少数の材質境界点を与える：点数・割合条件による境界の欠落。
- 15 cmの落ち込み、現在の障害物、未観測セル：各制約の保持。

実環境のIoU、芝生の誤許可率、境界誤差、物理的な道幅精度を算出する正解データは同梱していない。
進路候補数だけから最適閾値を選べない。メートル単位の境界精度にはカメラ内部・外部校正と
対応する正解境界が必要であり、歩道の恒久的な形状と現在の通行可否を分けて評価する。

## Jev等の外部モデル

このツールは数値条件をローカルコードで評価する。Jev、JEPA/V-JEPA、
画像セグメンテーション、外部の適応的地面分割モデルを呼び出す処理は実装されていない。
外部APIへのbag・画像送信も行わない。外部モデルを用いた精度・応答時間の評価機能はない。

Jevの提供仕様は[TypeSafe AI公式資料](https://docs.typesafe.ai/concepts/system-one)で確認できるが、
同資料のモデル能力を、このシステムで検証済みの路面認識能力として扱わない。
現行ツールに、モデルが閾値を自動選択したり、未観測・障害物・下方段差の制約を解除したりする経路はない。

## 実行と出力

```bash
source /opt/ros/jazzy/setup.bash
source install/setup.bash
PYTHONPATH=src/route_survey:src/gnss_lio_fusion:$PYTHONPATH \
python3 src/route_survey/tools/evaluate_ground_thresholds.py \
  --replay-dir <空き空間サンプルの評価ディレクトリ> --output <新規閾値評価ディレクトリ>
```

入力キャッシュは `evaluate_free_space.py` で作る。
比較入力の `scenes/` が出力先にあれば再利用するため、bagや座標変換が異なる場合は必ず出力先を分ける。

| 出力 | 内容 |
|---|---|
| `summary.json` | 設定別の候補数・内訳・反例・基準一致検査 |
| `decisions.json` | 各場面×各設定の判定・進路・地面セル数 |
| `scenes/` | 比較に用いる地面・障害物点群と入力条件 |
| `threshold_comparison.png` | 設定ごとの候補数 |
| `threshold_scene_73.png` | 73秒付近の画像とマスク比較。全区間の精度を表すものではない |

出力は作業PC内のファイル。iPhoneで共有する場合は本文の説明とPNGを閲覧版として添え、
ローカルパスをリモートから到達できる共有URLとして案内しない。
