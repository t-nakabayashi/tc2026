# GNSS/LIO融合の確認方法

## 評価する機能

GNSSの品質・基線長・方位による採否、LIO相対運動、車輪退避、観測時刻の内挿、
取付位置補正、補正速度制限、自律減速を対象とする。
現在の条件と制約は[詳細設計](gnss_lio_fusion_詳細設計書.md)を参照する。

## 単体・結合・走行の区別

`tests/` ではFIX/FLOAT、衛星不足、基線長変化、時刻逆行、位置跳躍、方位反転、
GPS復帰、共分散、傾斜取付、重力基準の破棄を確認する。
`check_fusion_dropout.py` はROS入力の途絶と車輪退避を確認する。

模擬走行は `obstacle_route_sim/tools/evaluate_terrain_trial.py` に
`--gnss --fusion --fastlio <実行ファイル>` を指定する。
`--building-gnss` で建物近傍FLOAT、`--lio-noise-profile conservative` で厳しいセンサ条件を選ぶ。
`--baseline-shift` と `--baseline-shift-after` で基線長変化を注入できる。
共通UIを含む操作確認は[icart_bringup](../../icart_bringup/README.md)を使う。

保存観測の再生はevaluate_fusion_replay.py、同一走行の分析はreview_fusion_trial.pyを使う。
再生で改善した推定値は、その値で車体を制御した閉ループ走行の結果ではない。
欠けた入力・品質を推測して補完したデータは、実観測と区別する。

## 指標と解釈

GNSS・融合の絶対位置を真値へ事後位置合わせしない。LIO単独は初回座標合わせの条件を明示する。
時刻を対応させてXY/yaw誤差、経路線分への横ずれ、入力欠落、棄却数、退避回数を測る。
FINISHEDだけで成功とせず、真値の終点距離・停止速度・接触・経路逸脱も確認する。

推定共分散は実測誤差の保証値ではない。FIXの共通bias、LIO退化、車輪スリップ、
同時劣化が残り得る。模擬モデルの成立だけで実機の精度や全周走行を認定しない。
