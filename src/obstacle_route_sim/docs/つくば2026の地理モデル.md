# つくば2026の地理モデル

## 対象

同梱モデルは約809×434 mの範囲と、図上トレースした約2.224 km・1,142点の検証経路を持つ。
公開地理情報から生成した試験環境であり、現地測量や本番経路承認を代替しない。
初めて利用する場合は[同梱地図](../maps/tsukuba2026/README.md)を使い、再取得・再生成は不要である。

## 2. 資料・位置合わせ・精度

| 入力 | 用途・出典 | 制限 |
| --- | --- | --- |

| OpenStreetMap | [地図](https://www.openstreetmap.org/#map=17/36.08375/140.07950) | 建物輪郭・高さタグ・道路・樹木・駐車場等。欠落や更新差がある |

Esri の当該範囲メタデータは `source/esri_extent_metadata.json` に保存する。
Vivid Advanced / GE01 / Vantor、BlockName は Vivid_Advanced_Tokyo_JP_24Q2 である。
画像タイルの細かさを実際の解像度・位置精度と混同しない。2026 年の現況写真ではない。
出典表記は Esri, Vantor, Earthstar Geographics, GIS User Community、
© OpenStreetMap contributors（ODbL）、国土地理院、つくばチャレンジ 2026 とする。
取得 URL とハッシュを source の manifest / provenance に残す。

水平座標は提供版の球近似ローカル平面である。厳密な測量座標系への校正は未実施。
DEM は中心標高を差し引く。GNSS 楕円体高原点 67.078 m は既存設定由来の仮定であり未校正。


## 生成と閲覧

prepare_full_course.pyが入力を準備し、reconstruct_full_course.pyが地形・建物・樹木・
航空写真の候補物体を構成する。audit_full_course.pyで経路と幾何の干渉を確認する。
preview_full_course.pyはブラウザ表示、render_full_course_views.pyは静止画像を生成する。
取得元・ハッシュ・設定は生成先のsourceとmanifestへ保存する。

地形を表すworld.json、環境environment.sdf、車体付きtrial.sdf、メッシュ、
概略経路route.csv等を出力する。生成入力・引数はparams/tc2026_reconstruction.jsonと各ツールの--helpを参照する。
同梱版は写真を含まない固定資産を使う。生成器で再取得すると提供元の更新により内容が変わり得る。

## 通路確保モデルと制約

clear_route_corridor.pyは経路周囲の通路確保のため、別モデルの物体を移動・削除する。
平面凸包や樹冠外接円を使い、元のCSVと航空写真は変更しない。
これは人為的な試験条件であり、現地の通行性を測定した修正ではない。
変更対象・移動量はcorridor_changes.jsonで確認する。

建物高さ・樹冠・車両・植栽は概形または推定値である。
縁石・階段・細いポール・通り抜け構造・材質反射・当日の人や車両を網羅しない。
地図生成の成功、模擬の完走、実環境の通行可否を別の判定とする。
